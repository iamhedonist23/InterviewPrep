SYSTEM DESIGN INTERVIEW QUESTIONS — LEVEL-WISE, INTERVIEW-STYLE
========================================================================================
These are realistic system-design prompts based on the supplied topic list and cross-checked against current interview-preparation sources. They are not claimed to be guaranteed questions from any company.

Junior themes: URL shortener, rate limiter, Pastebin, CAP, scaling, load balancing, caching.
Mid-level themes: newsfeed, ridesharing, chat, queues, consistent hashing, sharding, replication, resilience.
Advanced themes: streaming, payments, collaborative editing, consensus, multi-region systems, failure isolation, migrations.

========================================================================================
FRESHERS / JUNIOR
========================================================================================

1. [TinyURL] Design a URL shortening service. What are the requirements, data model, short-key generation strategy, and redirect flow?

2. [TinyURL] How would you generate unique short URLs using sequential IDs, Base62, or hashing? What collision issues arise?

3. [TinyURL] A shortened URL becomes extremely popular. How would you keep redirects fast and protect the database?

4. [TinyURL] How would you handle duplicate long URLs, URL expiration, and deletion?

5. [Rate Limiter] Design a rate limiter for an HTTP API. What happens when a client exceeds its limit?

6. [Rate Limiter] How does a token-bucket algorithm work, and how does it handle bursts?

7. [Rate Limiter] Compare token bucket and leaky bucket. When would you choose each?

8. [Rate Limiter] How would you implement a distributed rate limiter across multiple application servers?

9. [Rate Limiter] Why might Redis be used for distributed rate limiting, and what happens if Redis is unavailable?

10. [Pastebin] Design a Pastebin-like service. What are the API, data model, and storage choices?

11. [Pastebin] When would you store paste content in a database versus object/blob storage?

12. [Pastebin] How would you implement paste expiration and automatic cleanup?

13. [Pastebin] How would you prevent users from consuming unlimited storage in Pastebin?

14. [CAP] Explain CAP theorem using a distributed database during a network partition.

15. [CAP] Give an example where consistency is more important than availability and explain why.

16. [Scaling] Explain vertical versus horizontal scaling and the main limitations of each.

17. [Scaling] You have one backend server and traffic is growing. How would you scale it?

18. [Load Balancing] What does a load balancer do when several application servers handle the same API?

19. [Load Balancing] How should a load balancer react when one backend server becomes unhealthy?

20. [Caching] Where would you introduce caching in a simple web application and what would you cache?

21. [Databases] When would you choose SQL over NoSQL for a new system?

22. [Replication] Why replicate a database, and what problems can occur when reads use replicas?

23. [Consistency] Compare strong consistency and eventual consistency with practical examples.


========================================================================================
MID-LEVEL
========================================================================================

24. [Twitter/X Feed] Design a Twitter/X-style newsfeed for users following thousands of accounts.

25. [Twitter/X Feed] Compare fan-out-on-write and fan-out-on-read for a social-media feed.

26. [Twitter/X Feed] How would you handle a celebrity with tens of millions of followers?

27. [Twitter/X Feed] How would you rank posts instead of simply showing them chronologically?

28. [Uber] Design the backend for a ride-hailing service that finds a nearby available driver.

29. [Uber] How would you find nearby drivers efficiently without scanning every driver?

30. [Uber] How would you update driver locations in near real time?

31. [Uber] Two riders request the same driver simultaneously. How do you prevent double assignment?

32. [Uber] How would you partition a ride-sharing system geographically at large scale?

33. [WhatsApp/Messenger] Design one-to-one chat. How does a message travel from sender to recipient?

34. [WhatsApp/Messenger] Why use WebSockets or another persistent connection for chat?

35. [WhatsApp/Messenger] How do you deliver messages when the recipient is offline?

36. [WhatsApp/Messenger] How would you handle message ordering, retries, and delivery status?

37. [WhatsApp/Messenger] How would you scale a very large group chat?

38. [Queues] Why introduce a message queue between services instead of synchronous calls?

39. [Queues] What is the difference between a task queue and an event stream such as Kafka?

40. [Distributed Systems] What is consistent hashing and why is it useful when servers are added or removed?

41. [Sharding] How would you shard a database and choose a shard key?

42. [Replication] What problems can replication lag create for an application?

43. [Resilience] How would you stop one slow downstream service from blocking every incoming request?

44. [Caching] What is a cache stampede and how would you prevent it?

45. [Caching] What is a cache avalanche and how can staggered TTLs help?

46. [API Gateway] What responsibilities would you put in an API gateway?

47. [Reverse Proxy] What is a reverse proxy and what problems does it solve?


========================================================================================
ADVANCED / SENIOR / STAFF
========================================================================================

48. [Video Streaming] Design a YouTube/Netflix-style video streaming platform from upload through global playback.

49. [Video Streaming] Why transcode one uploaded video into multiple resolutions and bitrates?

50. [Video Streaming] How does a CDN reduce video latency and origin load?

51. [Video Streaming] How would adaptive bitrate streaming react to changing network bandwidth?

52. [Payments] Design a distributed payment-processing system and prevent duplicate charges.

53. [Payments] How do idempotency keys work in a payment API, and where do you store the result?

54. [Payments] Payment succeeds at the provider but your service times out. How do you reconcile the transaction?

55. [Payments] How would payment, order creation, and notification failures recover independently?

56. [Payments] What consistency and durability requirements differ between a payment ledger and notifications?

57. [Collaborative Editing] Design a Google Docs-style collaborative document editor.

58. [Collaborative Editing] What problem do Operational Transformation and CRDTs solve?

59. [Collaborative Editing] How do clients receive edits in real time, and how do you handle reconnects?

60. [Collaborative Editing] How would you persist document state and edit history efficiently?

61. [Consensus] Why do distributed systems need consensus algorithms such as Raft or Paxos?

62. [Consensus] What problem does leader election solve?

63. [Multi-Region] How would you design an active-active service across two regions?

64. [Multi-Region] A network partition separates two active regions. What behavior and consistency trade-off do you choose?

65. [Failure Isolation] How can one slow downstream service cause a cascading failure?

66. [Failure Isolation] How do timeouts, retries, circuit breakers, bulkheads, and queues work together?

67. [Migration] How would you migrate a very large production database without downtime?

68. [Migration] Why is expand-and-contract useful when old and new application versions coexist?

69. [Distributed Storage] How would you design a highly available distributed key-value store?

70. [Distributed Lock] When do you need a distributed lock, and what failure modes must you handle?

71. [Observability] Design logging, metrics, tracing, and monitoring for a large distributed system.
