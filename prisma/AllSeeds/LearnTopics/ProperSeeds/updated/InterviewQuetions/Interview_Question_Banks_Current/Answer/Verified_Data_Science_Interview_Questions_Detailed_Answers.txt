1.  [REPORTED] Question : What do you understand by p-value? Level :
    Fresher / Entry-Level

Answer : A p-value is the probability, assuming the null hypothesis is
true, of observing a test statistic at least as extreme as the one
obtained from the sample. It measures how incompatible the observed data
are with the null hypothesis.

A small p-value means the observed result would be relatively unusual if
the null hypothesis were true, so we have evidence against the null
hypothesis. It does not mean that the probability that the null
hypothesis is true is small.

The p-value must be interpreted together with the significance level,
effect size, confidence interval, study design, and practical
importance. A statistically significant result can still have a tiny
business impact, while a practically important effect may fail to reach
significance with a small sample.

Example : Suppose an A/B test compares two conversion rates and produces
p = 0.02. With α = 0.05, the result is statistically significant under
the test assumptions, so we reject the null hypothesis. We still need to
examine the effect size and confidence interval to decide whether the
change is practically valuable.

2.  [REPORTED] Question : If we fail to reject the null hypothesis, do
    we accept the alternate hypothesis? Level : Fresher / Entry-Level

Answer : Failing to reject the null hypothesis does not mean that we
accept the alternate hypothesis. It means the evidence in the sample is
insufficient to reject the null hypothesis at the chosen significance
level.

In a simple two-hypothesis test, the alternative may be the logical
complement of the null, but statistically we should still phrase the
conclusion as “there is insufficient evidence to reject H0” rather than
“H1 is false” or “H0 is proven true.”

This distinction matters because a non-significant result can arise from
a genuinely small effect, high variance, inadequate sample size, or low
statistical power.

Example : If a test produces p = 0.30 with α = 0.05, we fail to reject
H0. We should say “the data do not provide sufficient evidence against
H0,” not “H0 has been proven true.”

12. [REPORTED] Question : How would you implement mean, median and mode
    in core Python without using library functions? Level : Intermediate

Answer : Mean is the arithmetic average, median is the middle value
after sorting, and mode is the most frequent value.

For an unsorted list, a mean requires one pass and a running sum. A
median can be obtained by sorting, typically O(n log n), then selecting
the middle element(s). Mode can be computed with a frequency dictionary
in expected O(n) time.

Median is generally more robust to extreme outliers than mean, while
mode is especially useful for categorical or discrete data.

Example :

    def stats(values):
        if not values:
            raise ValueError("empty input")
        mean = sum(values) / len(values)
        ordered = sorted(values)
        n = len(ordered)
        median = ordered[n // 2] if n % 2 else (ordered[n//2 - 1] + ordered[n//2]) / 2

        counts = {}
        for x in values:
            counts[x] = counts.get(x, 0) + 1
        mode = max(counts, key=counts.get)

        return mean, median, mode

13. [REPORTED] Question : How would you implement a Decision Tree from
    scratch in Python? Level : Intermediate

Answer : A Decision Tree recursively partitions the training data into
subsets that make the target values more homogeneous. For
classification, a common split criterion is Gini impurity or entropy;
for regression, variance or squared-error reduction can be used.

A from-scratch implementation needs to: evaluate candidate features and
thresholds, calculate split quality, choose the best split, recursively
create child nodes, stop according to conditions such as maximum
depth/minimum samples, and assign a prediction at a leaf.

The expensive part is evaluating many feature/threshold candidates. A
production implementation uses optimized algorithms and data structures,
but the from-scratch version is useful for understanding the learning
process.

Example :

    # Conceptual split scoring
    def gini(labels):
        n = len(labels)
        counts = {}
        for y in labels:
            counts[y] = counts.get(y, 0) + 1
        return 1 - sum((c / n) ** 2 for c in counts.values())

    # A full implementation would enumerate candidate feature thresholds,
    # compare weighted child impurity, then recurse until stopping criteria.

14. [REPORTED TOPIC] Question : Explain Gini impurity, threshold
    selection, tree depth and other Decision Tree parameters. Level :
    Intermediate

Answer : Gini impurity measures how mixed the classes are in a node. For
class probabilities p₁…pₖ, Gini is:

Gini = 1 − Σ pᵢ²

It is zero when every sample belongs to one class and larger when
classes are mixed. A tree evaluates candidate splits and prefers splits
that reduce weighted impurity.

Threshold selection means testing candidate cut points for a numeric
feature. Maximum depth controls tree complexity; larger depth can fit
more complex patterns but can also overfit. Minimum samples per
split/leaf and pruning can also control complexity.

15. [REPORTED] Question : Write SQL to find the third-highest salary.
    Level : Intermediate

Answer : There are multiple correct SQL interpretations depending on
whether “third-highest” means the third distinct salary or the third row
after sorting.

For the third distinct salary, a window-function solution is explicit:

    SELECT salary
    FROM (
        SELECT salary,
               DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
        FROM employees
    ) x
    WHERE rnk = 3;

DENSE_RANK() handles duplicate salaries correctly when distinct salary
levels are required.

        SELECT salary,

17. [REPORTED] Question : Write a Python program to find the index of
    the maximum number without using NumPy. Level : Intermediate

Answer : Track both the maximum value and its index while scanning the
list once. This avoids NumPy and requires O(n) time and O(1) extra
space.

    def max_index(values):
        if not values:
            raise ValueError("empty sequence")

        best_index = 0
        for i in range(1, len(values)):
            if values[i] > values[best_index]:
                best_index = i
        return best_index

This returns the first index of the maximum value. The behavior for an
empty list should be specified explicitly.

Example :

    values = [4, 12, 7, 12, 3]
    # max_index(values) -> 1
    # The function returns the first maximum index.

19. [REPORTED TOPIC] Question : Explain precision and recall. Level :
    Intermediate

Answer : Precision answers: among the items predicted positive, how many
were actually positive?

Precision = TP / (TP + FP)

Recall answers: among all actual positive items, how many did the model
find?

Recall = TP / (TP + FN)

Use precision when false positives are particularly costly, and recall
when false negatives are particularly costly. In many applications, the
threshold should be selected according to business costs rather than
automatically choosing 0.5.

Example : If a fraud model flags 100 transactions and 80 are actually
fraud, precision is 80%. If there are 200 fraudulent transactions in
total, recall is 40%.

21. [REPORTED] Question : Reverse a linked list. Level : Intermediate

Answer : An iterative linked-list reversal changes each node’s next
pointer to point to the previous node. Maintain three references:
previous, current, and next.

    def reverse(head):
        prev = None
        cur = head

        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt

        return prev

Time complexity is O(n) and auxiliary space is O(1). The critical edge
cases are an empty list and a single-node list.

Example : For 1 -> 2 -> 3 -> None, reversing produces
3 -> 2 -> 1 -> None.

23. [REPORTED] Question : Solve a valid-parentheses programming problem.
    Level : Intermediate

Answer : Use a stack. Push opening brackets; for each closing bracket,
verify that the stack is non-empty and that its top matches the closing
bracket.

    def valid_parentheses(s):
        pairs = {')': '(', ']': '[', '}': '{'}
        stack = []

        for ch in s:
            if ch in pairs:
                if not stack or stack.pop() != pairs[ch]:
                    return False
            else:
                stack.append(ch)

        return not stack

Time is O(n) and auxiliary space is O(n) in the worst case.

Example : {[()]} is valid because every closing bracket matches the most
recent unmatched opening bracket. {[(])} is invalid because ] does not
match the top (.

24. [REPORTED] Question : Find the longest increasing subsequence. Level
    : Intermediate

Answer : The Longest Increasing Subsequence (LIS) asks for the longest
subsequence whose values are strictly increasing; the selected elements
do not need to be adjacent.

A straightforward dynamic-programming solution defines dp[i] as the
length of the longest increasing subsequence ending at index i, giving
O(n²) time and O(n) space.

A more advanced solution maintains a tails array and uses binary search,
achieving O(n log n) time. The latter is usually the stronger interview
solution when only the length is required.

Example : For [10, 9, 2, 5, 3, 7, 101, 18], one LIS is [2, 3, 7, 101],
so the length is 4.
