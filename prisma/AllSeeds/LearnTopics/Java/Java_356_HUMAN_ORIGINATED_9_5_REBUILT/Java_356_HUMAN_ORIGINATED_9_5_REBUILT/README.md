# Java 356 — Human-Originated 9.5 Target Rebuild

This package contains 356 standalone Prisma seed files. The editorial standard is not “more paragraphs”; each topic is expected to explain the actual Java rule/API contract, show concrete code, explain observable behavior, cover edge cases and interview traps, and give production guidance.

Sources used for technical verification include the Java Language/VM specifications and current Java SE API documentation. For example, Scanner, BufferedReader, InputStreamReader, and PrintStream behavior was checked against Oracle Java SE documentation.

## Run
From the project root:

```bat
npx tsx prisma/LearnTopics/Java/Java_356_HUMAN_ORIGINATED_9_5_REBUILT/run-all.ts
```

The runner expects the project to have `tsx` installed and a configured Prisma Client/database.
