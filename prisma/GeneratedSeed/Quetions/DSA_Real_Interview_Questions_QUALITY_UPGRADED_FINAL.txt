Question : [REPORTED] Reverse a singly linked list. Reported by: Amazon SDE1; Microsoft SDE; Samsung Bangalore; other reports. Evidence: Amazon explicitly reported “Reverse a linked list”; Microsoft reported the same problem; Samsung reported reverse a linked list. Sources: - LeetCode Microsoft SDE interview experience - LeetCode Amazon SDE1 onsite experience - GeeksforGeeks Samsung Bangalore internship experience
Answer : Keep three pointers: prev, current, and next. Save current.next before changing the link, point current.next to prev, then move both pointers forward. Every node is visited once, so the time is O(n) and auxiliary space is O(1). The empty-list and one-node cases fall out naturally from the loop.

Code (Python):
```python
def reverse(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt
    return prev
```
Example : Input: 1 -> 2 -> 3 -> null. After reversal: 3 -> 2 -> 1 -> null. The important pointer moment is saving 2 before changing 1.next to null.

Question : [REPORTED] Implement an LRU cache. Reported by: Amazon, Microsoft, Joveo, OnlineSales AI, Flipkart, OLX Groups and other interview experiences. Sources: - LeetCode Amazon SDE1 onsite - LeetCode Microsoft SDE - LeetCode Joveo SDE1 - LeetCode OnlineSales AI SDE2 - GeeksforGeeks Flipkart SDE II - GeeksforGeeks OLX Groups Interview variants reported by Joveo SDE1, Microsoft SDE, OnlineSales AI SDE2, Flipkart SDE II, OLX Groups and other reports include O(1) get/put, a doubly linked list + hash map, and implementing it on paper.
Answer : The standard LRU design uses two structures together: a hash map for fast key lookup and a doubly linked list for recency order. The map points to list nodes. On get(), move the node to the front; on put(), update or insert at the front and remove the tail when capacity is exceeded. Lookup, unlink, insert, and eviction are O(1) on average, with O(capacity) space.

Code sketch (Python):
```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)
```
This sketch uses Python's ordered dictionary; in a language where that structure is unavailable, the usual interview implementation is a hash map plus a doubly linked list.
Example : With capacity 2: put(1,A), put(2,B), get(1) makes 1 most-recent, then put(3,C) evicts key 2.

Question : [REPORTED] Modify an LRU cache to support TTL/expiration. Reported by: Microsoft Senior Software Engineer. Source: LeetCode Microsoft Senior SE interview experience, March 2026.
Answer : Keep the normal LRU structure—a hash map plus a doubly linked list—but add an expiration timestamp to each entry. A get() first checks whether the key exists and whether its TTL has expired; an expired entry is removed before returning a miss. Capacity eviction still removes the least-recently-used entry. Average get/put can remain O(1), but proactive cleanup of expired entries may require an additional time-based structure such as a min-heap if expired keys must be removed even when they are never accessed.
Example : If key 42 has value X with TTL 5 seconds and the cache is queried after 7 seconds, get(42) should behave as a miss and remove the expired entry.

Question : [REPORTED] Discuss concurrency/thread safety for an LRU cache. Reported by: Microsoft Senior Software Engineer. Source: LeetCode Microsoft Senior SE interview experience, March 2026.
Answer : The ordinary hash-map-plus-list design is not thread-safe by itself because get() can mutate recency order while put() changes both structures. A simple correct design can protect the whole operation with a mutex. If contention becomes a bottleneck, consider finer-grained locking or sharding, but only after defining the consistency requirements. The key interview point is that O(1) algorithmic complexity does not automatically mean safe concurrent behavior.
Example : Two threads calling get(1) can both modify the recency list. A mutex around the lookup-and-move operation prevents list corruption; a read-only lock would not be enough because get changes state.

Question : [REPORTED] Solve the Trapping Rain Water problem. Reported by: Amazon SDE1. Source: GeeksforGeeks Amazon Interview Experience SDE-1.
Answer : A strong O(n), O(1)-space solution uses two pointers. Keep left and right boundaries and the highest wall seen from each side. Whichever side has the smaller current height can be resolved because its water level is limited by that side’s maximum. Add leftMax-leftHeight or rightMax-rightHeight as appropriate, then move inward.

Code (Python):
```python
def trap(h):
    left, right = 0, len(h) - 1
    left_max = right_max = 0
    water = 0
    while left <= right:
        if h[left] <= h[right]:
            left_max = max(left_max, h[left])
            water += left_max - h[left]
            left += 1
        else:
            right_max = max(right_max, h[right])
            water += right_max - h[right]
            right -= 1
    return water
```
Example : For heights [0,1,0,2,1,0,1,3,2,1,2,1], the trapped water totals 6 units.

Question : [REPORTED] Solve Spiral Matrix. Reported by: Joveo SDE1. Source: LeetCode Joveo SDE1 interview experience.
Answer : Maintain four boundaries: top, bottom, left, and right. Traverse the top row, right column, bottom row in reverse, and left column upward, shrinking the corresponding boundary after each pass. Check the boundaries before the second pair of traversals so a single remaining row or column is not emitted twice. Time is O(rows*columns) and extra space is O(1), excluding the output.

Code (Python):
```python
def spiral(matrix):
    out = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        out += matrix[top][left:right + 1]
        top += 1
        for r in range(top, bottom + 1):
            out.append(matrix[r][right])
        right -= 1
        if top <= bottom:
            out += matrix[bottom][left:right + 1][::-1]
            bottom -= 1
        if left <= right:
            for r in range(bottom, top - 1, -1):
                out.append(matrix[r][left])
            left += 1
    return out
```
Example : For [[1,2,3],[4,5,6],[7,8,9]], spiral traversal is 1,2,3,6,9,8,7,4,5.

Question : [REPORTED] Solve Next Permutation. Reported by: Amazon SDE1. Source: LeetCode interview experience by candidate reporting Amazon SDE1.
Answer : Scan from the end to find the first index i where a[i] < a[i+1]. Then find the smallest value to the right that is larger than a[i], swap them, and reverse the suffix. If no such i exists, the sequence is already the largest permutation, so simply reverse it to obtain the smallest. The algorithm is O(n) time and O(1) auxiliary space.

Code (Python):
```python
def next_permutation(a):
    i = len(a) - 2
    while i >= 0 and a[i] >= a[i + 1]:
        i -= 1
    if i >= 0:
        j = len(a) - 1
        while a[j] <= a[i]:
            j -= 1
        a[i], a[j] = a[j], a[i]
    a[i + 1:] = reversed(a[i + 1:])
```
Example : For [1,2,3], the next permutation is [1,3,2]. For [3,2,1], there is no larger permutation, so reverse it to [1,2,3].

Question : [REPORTED] Solve House Robber. Reported by: Amazon SDE1. Source: LeetCode interview experience by candidate reporting Amazon SDE1. ==================================================== 4. STRINGS ====================================================
Answer : At each house you have two choices: skip it or take it and therefore skip the previous house. Keep two values representing the best result before the current position and the best result if the current house is considered. The transition is max(previousBest, twoBack + current). This is O(n) time and can be reduced to O(1) space.

Code (Python):
```python
def rob(nums):
    prev2 = prev1 = 0
    for x in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1
```
Example : For houses [2,7,9,3,1], the best non-adjacent total is 12 from 2+9+1.

Question : [REPORTED] Find the longest palindromic substring. Reported by: Amazon SDE1; Amazon interview experience. Sources cited in the original file.
Answer : For the longest palindromic substring, expand around every possible center. Each character is a center for an odd-length palindrome, and each gap is a center for an even-length palindrome. Expand while the characters match and retain the longest range. The straightforward solution is O(n²) time and O(1) auxiliary space; Manacher’s algorithm can reduce the time to O(n), but it is usually unnecessary unless the constraints demand it.

Code (Python):
```python
def longest_palindrome(s):
    best = ""
    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1
        return s[l + 1:r]
    for i in range(len(s)):
        for l, r in ((i, i), (i, i + 1)):
            p = expand(l, r)
            if len(p) > len(best):
                best = p
    return best
```
Example : For "babad", both "bab" and "aba" are valid longest palindromic substrings. For "cbbd", the answer is "bb".

Question : [REPORTED] Reverse a stack using recursion. Reported by: PharmEasy SDE1. Source: LeetCode candidate interview experience.
Answer : Use recursion to remove the top element until the stack is empty. Then insert each removed element at the bottom while the recursive calls return. The key helper is insertAtBottom, which temporarily removes elements until the bottom is reached. This uses O(n²) time in the straightforward implementation and O(n) call-stack space.

Code (Python):
```python
def insert_bottom(stack, x):
    if not stack:
        stack.append(x)
        return
    top = stack.pop()
    insert_bottom(stack, x)
    stack.append(top)

def reverse_stack(stack):
    if not stack:
        return
    top = stack.pop()
    reverse_stack(stack)
    insert_bottom(stack, top)
```
Example : Stack [1,2,3] becomes empty during recursive removal, then 1 is inserted at the bottom first, followed by 2 and 3, restoring [1,2,3] in reversed-processing order as required by the helper.

Question : [REPORTED] Design a stack that supports getMin in O(1). Reported by: OLX Groups. Source: GeeksforGeeks OLX Groups Interview Experience.
Answer : Use a second stack that stores the minimum value seen at each depth. On push, push min(value, currentMinimum) onto the minimum stack; on pop, remove from both stacks. Then getMin() simply reads the top of the minimum stack. All three operations are O(1), with O(n) extra space.

Code (Python):
```python
class MinStack:
    def __init__(self):
        self.data = []
        self.mins = []

    def push(self, x):
        self.data.append(x)
        self.mins.append(x if not self.mins else min(x, self.mins[-1]))

    def pop(self):
        self.mins.pop()
        return self.data.pop()

    def getMin(self):
        return self.mins[-1]
```
Example : Push 5, 2, 7. getMin() returns 2. Pop 7 and getMin() is still 2; pop 2 and getMin() becomes 5.
